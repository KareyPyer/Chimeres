# 🌌 🧬 🎨 Grimoire d'Invocation — ArcheoSymbolic Chronicle

Voici un recueil d'invocations pour éveiller la Chimère, classées par intention créative. Chaque commande produit une simulation unique, une épidémie narrative aux saveurs différentes.

---

## 🌱 **1. L'Éveil Doux — Découverte Rapide**

Pour une première rencontre avec la Chimère, en 30 secondes :

```bash
python ArcheoSymbolic_Chronicle.py \
    --seed 2075 \
    --steps 25 \
    --pop-total 80 \
    --root-theme rituel \
    --mutation-prob 0.04
```

> 🪷 *Une simulation courte, apaisante, où un rituel ancestral se propage dans une petite communauté. Idéal pour comprendre la mécanique sans se noyer dans les données.*

---

## 🔥 **2. L'Explosion Créative — Mutation Intense**

Quand vous voulez voir la Chimère **diverger esthétiquement** :

```bash
python ArcheoSymbolic_Chronicle.py \
    --seed 4242 \
    --steps 60 \
    --pop-total 200 \
    --root-theme émergence \
    --mutation-prob 0.08 \
    --symbolic-generations 5 \
    --symbolic-pop 10 \
    --export-csv ./output/explosion_csv \
    --export-neo4j ./output/explosion_neo4j
```

> 🧬 *Une forte probabilité de mutation combinée à un thème "émergence" produit une **radiation esthétique** : des dizaines de souches naissent, chacune avec son glyphe, sa couleur, son émotion dominante. Le graphe Neo4J révèle une phylogénie visuelle fascinante.*

## 📖 **Comment Explorer les Résultats**

### 🔍 **CSV — Analyse Quantitative**
```bash
# Voir les souches dominantes
head -20 output/opus_magnum_csv/strains_state.csv

# Compter les factions
wc -l output/opus_magnum_csv/factions.csv

# Analyser la mémoire épisodique
grep "mutation" output/opus_magnum_csv/episodic_memory.csv | wc -l
```

### 🦈 **Neo4J — Exploration Graphique**
```cypher
// Voir l'arbre de mutations
MATCH path = (parent:Strain)-[:MUTATED_INTO*]->(child:Strain)
WHERE NOT (parent)-[:MUTATED_INTO]->()
RETURN path LIMIT 50

// Trouver les artefacts les plus "beaux"
MATCH (a:Artefact)
RETURN a.glyph, a.color, a.aesthetic_score
ORDER BY a.aesthetic_score DESC
LIMIT 10

// Voir les factions et leurs alliances
MATCH (f:Faction)-[:ALLIED_WITH]->(ally:Faction)
RETURN f.name, collect(ally.name) as alliances
```

### 🎨 **Prompt de Diffusion — Génération d'Image**
Le fichier `diffusion_prompt.txt` contient un prompt prêt à copier-coller dans :
- **Grok** (xAI) : pour un rendu photoréaliste
- **Gemini** (Google) : pour un rendu artistique/surréaliste
- **DALL-E** (OpenAI) : pour un rendu fantasy/cyberpunk
- **Midjourney** : pour un rendu majestueux avec `--ar 16:9`

## 🌸 **Conseils du Jardinier de Chimères**

1. **Commencez petit** : `--steps 30 --pop-total 80` pour comprendre la mécanique.
2. **Expérimentez les thèmes** : chaque thème produit une **esthétique radicalement différente**.
3. **Augmentez la mutation** : `--mutation-prob 0.08` pour voir la Chimère **diverger**.
4. **Exportez tout** : les CSV et Neo4J révèlent des patterns invisibles en temps réel.
5. **Générez des prompts** : le fichier `diffusion_prompt.txt` est une **synthèse poétique** de l'épidémie.
6. **Variez les graines** : `--seed 42` vs `--seed 1337` produisent des **univers parallèles**.
